# PROXY GO

Website perkenalan kelompok Pekan Ilkomerz.

## Struktur
- `index.html` — seluruh struktur/alur halaman
- `style.css` — visual prototype
- `script.js` — data 11 anggota, popup CV, Pokéball interaction
- `assets/` — tempat foto asli anggota, memories, dan aset lain

## Alur
Loading → Hero → About / Egg → Pokéball → 11 Trainer Cards → Penanggung Jawab → Memories → Closing → Jargon.

## Yang sengaja dibuat placeholder
1. Foto kelompok/header.
2. Foto 11 anggota.
3. Foto Penanggung Jawab.
4. Dokumentasi memories.
5. Nama, tanggal lahir, kota, sosial media.
6. CV ATS.
7. Detail efek Pokémon per anggota.

## Cara mengembangkan
- Ganti placeholder `.member-img` dengan `<img>` atau background-image.
- Hubungkan setiap kartu dengan file CV ATS masing-masing.
- Tambahkan efek khusus berdasarkan Pokémon.
- Tambahkan animasi Pokéball open.
- Tambahkan GSAP/Lenis atau library lain jika tim ingin scroll yang lebih cinematic.
- Pertahankan alur besar agar ide visual tetap konsisten.

## Catatan desain
Palet utama: dark navy / charcoal / off-white / Pokémon red.
Merah dipakai sebagai accent, bukan memenuhi seluruh halaman.
